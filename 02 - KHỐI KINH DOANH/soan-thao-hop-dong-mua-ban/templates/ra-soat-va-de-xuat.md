# PHIẾU RÀ SOÁT VÀ ĐỀ XUẤT

Mẫu điền nghiệp vụ; ô trống có chủ đích. Không phải kết quả đã kiểm hoặc phê duyệt.

## Trạng thái và phiên bản

Ghi BẢN NHÁP / CHỜ DUYỆT / NỘI DUNG ĐÃ ĐƯỢC DUYỆT theo căn cứ. Ghi phiên bản hợp đồng, mẫu áp dụng, phạm vi và người kiểm.

## Bảng rà soát

| Hạng mục | Giá trị dự kiến dùng | Nguồn/phiên bản/ngày tra | Kết quả kiểm | Người cần xác nhận/quyết định |
|---|---|---|---|---|
| Hồ sơ hai bên và căn cứ người ký | | | | |
| Hàng hóa, số lượng, đơn vị, kỹ thuật | | | | |
| Giá, chiết khấu, chính sách và ngoại lệ | | | | |
| Thuế, thời điểm áp dụng, xác nhận kế toán | | | | |
| Phép tính, số tiền bằng chữ, lịch thanh toán | | | | |
| Giao hàng, nghiệm thu, bảo hành, nghĩa vụ khác | | | | |

## Phép tính

Ghi đầu vào + nguồn + công thức + đơn vị + kết quả + quy tắc làm tròn. Tách theo nhóm thuế; phân biệt giá trước/sau thuế và tránh cộng trùng.

## Mâu thuẫn và phương án riêng

| Vấn đề | Nguồn và nội dung khác nhau | Phương án | Tác động/rủi ro | Quyết định cần có |
|---|---|---|---|---|
| | | | | |

Không tự chọn khi mâu thuẫn chưa được giải quyết.

## Đề xuất sửa điều khoản — ngoài bản hợp đồng chờ duyệt

| Điều khoản mẫu | Nội dung đề xuất | Lý do/căn cứ | Nghĩa vụ/rủi ro thay đổi | Người có quyền duyệt |
|---|---|---|---|---|
| | | | | |

## Lịch sử chỉnh bản làm việc

| Phiên bản | Nội dung thay đổi | Phản hồi/căn cứ duyệt | Phần đã kiểm lại | Trạng thái |
|---|---|---|---|---|
| | | | | |

## Bàn giao

Nêu phần đã hoàn thành, phần chưa đạt, quyết định cần có và nhiệm vụ tiếp theo. Không suy trạng thái nội dung đã duyệt thành quyền ký/gửi.
